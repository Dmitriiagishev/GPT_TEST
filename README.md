# Цветной ASCII-додекаэдр

Вращающийся правильный додекаэдр на Rust: 12 заполненных пятиугольных граней,
перспективная проекция, удаление невидимых граней и Z-буфер. Источник света
находится сверху слева со стороны наблюдателя; у каждой грани свой цвет.
Яркость передаётся одновременно цветом и ASCII-символами `.:-=+*#%@`.

## Запуск на Arch Linux

Требуется Rust 1.88 или новее. Установите компилятор и инструменты сборки:

```sh
sudo pacman -S --needed rust base-devel
```

В каталоге проекта выполните:

```sh
cargo run --release --locked
```

Для первого скачивания зависимостей нужен интернет. После сборки программу
можно запускать напрямую: `./target/release/ascii-dodecahedron`.

Нужен интерактивный терминал с ANSI и желательно 24-битным цветом,
например Kitty, Alacritty, Konsole или GNOME Terminal. Используйте моноширинный
шрифт. Графический сервер, GPU, внешние модели и дополнительные сервисы не нужны.

## Управление

- **Пробел** — приостановить или продолжить вращение.
- **R** — вернуть исходный угол.
- **Q**, **Esc** или **Ctrl+C** — выйти.

Программа работает в альтернативном экране и при штатном выходе или ошибке
ввода-вывода восстанавливает курсор, перенос строк и режим терминала.

## Размер и пропорции

Размер окна проверяется каждый кадр. При изменении окна буферы пересоздаются,
а масштаб выбирается по ширине и высоте, чтобы додекаэдр целиком помещался
над строкой управления. Один ASCII-пиксель — одна ячейка терминала:
масштабирование меняет число ячеек, занимаемых фигурой. Размер самого шрифта
контролирует терминал.

Если терминал сообщает размеры окна в физических пикселях, программа вычисляет
пропорции ячейки из этих данных. Иначе используется типичное отношение высоты
к ширине 2:1. Поэтому фигура не растягивается из-за прямоугольных символов
при стандартных пропорциях шрифта. При нестандартном шрифте и отсутствии
пиксельных размеров точность пропорций ограничена этим допущением.

Целевая частота — 60 кадров в секунду; скорость вращения зависит от времени,
а не от числа кадров. Очень маленькое окно уменьшает детализацию фигуры.

## Снимок и проверка

Один кадр размером 100 столбцов × 35 строк без интерактивного режима:

```sh
cargo run --release --locked -- --snapshot 100 35
```

Снимок тоже содержит ANSI-цвета, поэтому его можно сохранить в файл и открыть
через `less -R`. Для этого режима предполагаются ячейки 2:1.

```sh
cargo test --locked
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
```

Тесты проверяют правильность геометрии, направление освещения, перекрытие
поверхностей, заполнение без дыр, масштабирование и вращение.
